📋 تایپ‌های کلیدی
═══════════════════════════════════════════════════════

AthleteProfile:
  id, name, age, gender, height, weight, targetWeight?,
  activityLevel, experience, trainingDays, sessionDuration,
  location, equipmentType, customEquipment, equipment,
  injuries[], limitations[], avoidedExercises[],
  primaryGoal, secondaryGoal?, targetMuscles[],
  programType, timeline, trainingHistory,
  strengthRecords (legacy),
  strengthRecordsExtended? (squat/bench/deadlift/ohp/row/pullUp/dip),
  bodyMeasurements, dietaryGoal, dietType, foodAllergies, favoriteFoods,
  bodyFrame? ('ectomorph'|'mesomorph'|'endomorph'),
  dominantLimbLength? ('short'|'average'|'long')

Exercise (engine):
  id, name, englishName, aliases?, primaryMuscle, secondaryMuscles[],
  type, movementPattern, equipment[], equipmentDetails?,
  difficulty, injuryRisk (per-area), substitutes[], cues[],
  repRanges {hypertrophy/strength/endurance}, rirRange,
  restSeconds, tempo?, isCompound, isSpineSensitive, tags

GeneratedSet (فعلی):
  setNumber, targetReps, targetRIR, restSeconds,
  tempo?, suggestedWeight?, lastWeight?
  + باید اضافه شه: technique?, techniqueConfig?, week1RM?, week?

GeneratedExercise:
  exerciseId, name, englishName, primaryMuscle, secondaryMuscles[],
  type, sets[], notes?, substituteId?

GeneratedProgram:
  id, name, goal, experience, splitType, trainingDaysPerWeek,
  sessionDuration, durationWeeks, createdAt, days[], restDays[],
  weeklyVolumeSummary,
  metadata { engineVersion, generatedFrom, priorityMuscles?,
             goal?, experience?, validationScore?, injuries?, splitType? }
  + باید اضافه شه: systemName?, periodizationPhase?, weeklyProgression?

WorkoutProgram (ذخیره در localStorage):
  id, profileId, name, duration, createdAt, trainingDays,
  splitType?, goal?, experience?, restDays?, weeklyVolumeSummary?,
  days: WorkoutDay[], metadata (همان + injuries)

WorkoutExercise (در WorkoutDay.exercises):
  { id, exerciseId, name, sets, reps, rest, tempo, rir,
    targetMuscle, primaryMuscle, secondaryMuscles[], type,
    englishName, substitute?, notes? }

═══════════════════════════════════════════════════════
⚠️ قوانین سختگیرانه همکاری
═══════════════════════════════════════════════════════

1. فقط دستور Git Bash بده — من کپی/پیست می‌کنم.
   هیچ توضیح طولانی، هیچ کد مستقیم در چت نده.

2. خلاصه و سریع — هر گام حداکثر 30 خط bash.

3. گام به گام — بعد از هر دستور، منتظر خروجی من بمان.
   قبل از رفتن به گام بعد، مطمئن شو typecheck پاس شده.

4. Console/Debug تکراری ممنوع — من نمی‌تونم Console بزنم.
   مشکل رو از روی کد تشخیص بده، نه runtime.

5. فایل‌های جدید را کامل با cat > file << 'EOF' بساز —
   نه sed پیچیده برای ساخت فایل از صفر.

6. اصلاح فایل موجود با awk/sed — اگه فقط چند خط تغییر می‌کنه،
   از awk استفاده کن. از python استفاده نکن (نصب نیست).

7. هر گام باید typecheck تمیز بده —
   بعد از هر تغییر: npm run typecheck 2>&1 | tail -10

8. قبل از دستور، یک خط توضیح بده — «این چیکار می‌کنه» — نه بیشتر.

9. Git flow: بعد از هر فاز → commit + tag + push خودکار.

10. اگر خطای typecheck داد — خروجی رو می‌فرستم، دقیق fix کن،
    نه راه‌حل generic.
